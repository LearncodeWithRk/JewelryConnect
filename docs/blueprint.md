# **App Name**: JewelryConnect

## Core Features:

- Homepage Showcase: Display best jewelry pieces with an intro and prominent "Book a Consultation" CTA linking to the booking page or WhatsApp chat.
- About Page: Share your story and journey as a jewelry influencer.
- WhatsApp Booking Integration: Integrate a WhatsApp button for users to instantly message to schedule consultations. The LLM will use the "tool" to determine whether to respond automatically or to send the message to the influencer to handle personally.
- Consultation Options: Provide details about consultation types (Personal Styling, Custom Design, Jewelry Care Tips).
- Automated Reminders: Set up automated reminders for clients through WhatsApp before booked consultations.
- Personalized follow ups: Create custom links for different consultation types for tailoring of conversation
- Blog: Create blog content to establish expertise and attract audience to the website

## Style Guidelines:

- Primary color: Gold (#FFD700) to reflect luxury and sophistication.
- Background color: Off-white (#FAF9F6) for a clean and elegant backdrop.
- Accent color: Teal (#008080) for highlights and CTAs, providing a vibrant contrast.
- Body text: 'Inter' (sans-serif) for easy readability and a modern feel; headline font: 'Playfair' (serif) for an elegant feel. Note: currently only Google Fonts are supported.
- Use minimalist icons for consultation types and navigation.
- Image-heavy design with high-quality product photography and styled shoots.
- Subtle hover effects on jewelry items to highlight details.
